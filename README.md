# Remenguiny

A delightful memory game featuring penguins, powered by blockchain technology and AI integration.

## 🌟 Project Context

Remenguiny is a live, working product built on Abstract Mainnet, featuring the unique characters of its two founders, Cygaar and Luka. The game combines engaging memory mechanics with blockchain technology to create an immersive and rewarding experience.

### Current Features

- Memory matching gameplay with progressive difficulty
- Character system based on the founders' personas
- Abstract Mainnet integration
- Live and operational product

### Existing Architecture

- Built on Abstract Mainnet
- Integrated with Abstract Gateway Client (`@abstract-foundation/agw-client`)
- React-based frontend with Web3 capabilities
- Robust state management and game mechanics

- React 19.0.0
- React Three Fiber (^9.0.0-alpha.8)
- Crossmint SDK
  - Client SDK React UI (^1.19.20)
  - Client SDK Base (^1.5.1)
- Abstract Foundation
  - AGW Client (^1.4.0)
  - AGW React (^1.5.1)

### Preservation Strategy

To protect the existing game mechanics while adding new features:

1. **Modular Architecture**

   - New features as independent modules
   - Core game logic preservation
   - Optional UI elements

2. **Feature Flagging**

   - Controlled feature rollout
   - Easy rollback capability
   - A/B testing support

3. **State Management**
   - Isolated state for new features
   - Clean integration points
   - No core state modification
